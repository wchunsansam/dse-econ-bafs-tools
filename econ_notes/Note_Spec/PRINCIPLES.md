# 設計意念與方法

寫新章前先對齊這些原則。細節 class 與檔案在 LAYOUT / WORKFLOW。

## 1. 產品定位

這是**課堂演示用的筆記頁**，不是電子課本、不是 GoodNotes、也不是 App Store 應用。

同時要服務三種現場：

| 現場 | 筆記要做的事 |
|---|---|
| 投影提問 | 完整／填空／點揭三種模式；答案可藏可揭 |
| iPad 書寫 | 在現有長頁上畫，不夠就加空白頁；筆跡跟文字走 |
| 列印帶走 | A4、隱藏頂欄與教具鈕、填空仍是空線 |

三種現場共用同一份 HTML。不要為「紙本版／投影版／平板版」做三套內容。

## 2. 一章一頁、長網頁

一章 = 一條可捲動的網頁，不是一頁一頁的紙。目錄用節號跳到頁內錨點。

含義：

- 「加紙」是在底部加空白書寫區，不是插入 PDF 第 N 頁。
- 畫筆座標綁在筆記紙面，不綁在視窗。縮放時墨水必須跟文字。
- 不要把一章拆成很多獨立 HTML（1.1.html、1.2.html），除非老師明確要求。

## 3. 課本範圍決定筆記範圍

該章**這一版教科書的節次**是目錄的唯一來源。

- 書本章沒有的課題：不要為了「舊筆記有」或「感覺應該教」而塞進來。一句「見後續章」可以；整節不行。
- 書本章有、舊材料沒有的：要補（定義、應試攻略、該頁官方欄目）。
- 考試權重不平均：筆記篇幅跟隨書（核心機制寫厚、陪襯概念寫薄），教具也把力氣放在考試會反覆考的機制，不要每個小標都配一個小工具。

開始寫之前，先用該章中英目錄列一張「本章有／本章沒有」。沒有對過書，不要開寫。

## 4. 兩層內容，不要混

| 層 | 誰的聲音 | 典型區塊 |
|---|---|---|
| **官方層** | 課本 | 定義核心句、應試攻略準則、小測試、例題拆解題幹、公開試題 |
| **課堂層** | 這間課室 | 解說段落、生活例子、小練習、生活案例、解題思路、教具 |

官方層：**照該語文書**，不要改成更口語、不要換人名、不要「優化」題幹。

課堂層：**不要整段抄課本個案**。用香港中四生會遇到的情境改寫（放學、兼職、港鐵／專線小巴、飯堂、補習、假期工）。計算骨架可以跟書（金錢成本、所放棄的收入、全部成本、哪邊較低），故事與人名換成課堂那套。

兩層在頁面上可以交錯（概念後面接課堂例子，再接該頁的官方框），但讀者要分得出誰是書、誰是課室。官方框有標籤與頁碼；課堂練習沒有課本頁碼。

## 5. 中英平行，不是互譯

中文筆記跟中文書；英文筆記跟英文書。兩本書的例子、專有名詞、甚至句式都可以不同。

改英文時：打開英文書該頁。書裡有的句子、文法、用詞（即使讀起來不自然）優先跟書。書沒有對應段，才用課堂英譯。

禁止：把中文筆記譯成英文交差，或把英文筆記譯成中文交差。

## 6. 課堂要「演得出」

每個考點在頁面上應能被指著講，而不是只有一段散文。優先順序：

1. **一句可填空的定義**（關鍵詞包在 `.ans`）
2. **對照或流程**（兩欄、表、直線因果、分叉鏈）——課本有中間格就保留中間格
3. **一個課堂例子**（短、本地、可投影）
4. **一條應試攻略**（分點、各有正確例與陷阱）
5. **一題能點揭的小練習**（測剛才那一點，不是綜合卷）
6. **若靜態圖講不完**，才做教具（見 TOOLS.md）

不要用長文取代圖。也不要為了「看起來豐富」而堆沒有教學功能的裝飾。

## 7. 填空是考點，不是刪字遊戲

`.ans` 只包**考試要寫得出的詞或短語**。不要把整句藏起來。長定義用語用 `.ans.wide`。

同一句裡可以有多個空。學生在「填空」模式應能從句子結構看出要填甚麼類型的詞。

點揭模式是給投影提問：先空、點該格才出現、再點可藏。不要做成一次揭開全頁。

## 8. 共用殼，不重做頂欄

語言、完整／填空／點揭、畫筆、加紙、教具、書本練習／答案、列印、分享，全部由組裝器注入。新章只提供內文與 metadata。

不要在某一章的 body 裡複製一套工具列，也不要為某一章改 `notes.css` 的顏色系統，除非老師要求全站改。

## 9. 觸控與現場硬體

預設裝置是 **iPad Safari（投影或學生手持）**，其次才是桌面 Chrome。

- 輸入框字級 16px，減少 iOS 自動放大。
- 可點控件要夠大；頂欄為了一列放下可以比 44px 略矮，但點揭空格、教具鈕、lab 分頁仍以手指為準。
- 畫筆開啟時：不捲動、不縮放、不點揭、不開連結。關閉畫筆才恢復瀏覽。在提示裡寫清楚。
- 頂欄在雙指縮放時仍要留在可視區（已有共用腳本）。新章不必重寫。

## 10. 插圖與版權

- 說明文字寫在 HTML，不燒進圖。
- 不要把課本插圖或長段原文掃描公開上網。
- 校本圖放 `econ_notes/img/`。已有圖凍結：不要重繪，除非老師要求。
- 同一章同一套畫風。人物預設：女生頭髮及肩，不要馬尾（除非老師另說）。
- 圖是輔助，不是裝飾。沒有圖也能把概念講完時，不要為了「有圖」而加。

## 11. 網站還是網站

學生打開的永遠是這個 HTML 站。離線、加到主畫面、解鎖，都是全站行為。

不要：為筆記做第二個 App、用原生包裝、在章內自建 service worker、或告訴學生「要切換到離線版 App」。

## 12. 穩定性高於新花樣

每一章的價值是**同一套課堂動作可預期**：切語言、藏答案、畫一筆、跳教具、印一張。

新元件只有在現有 class 真的表達不了時才加，而且要進共用 CSS，讓下一章也能用。不要在單章 body 寫一大段 `<style>`。
