Add to Home Screen (iPad and Android)

iPad / iPhone — Safari

  1. Open this site in Safari (not Chrome).
  2. Tap Share (the square with an arrow pointing up).
  3. Scroll down, tap Add to Home Screen, then Add.

Android tablet / phone — Chrome

  1. Open this site in Chrome.
  2. Tap the three-dot menu at the top right.
  3. Tap Add to Home screen or Install app, then confirm.

An icon appears on the Home Screen. Opening it is full screen, with no browser address bar. This is not an App Store or Play Store listing.

Use without internet

This is still the same HTML website. The browser can keep a copy on the iPad or Android tablet. With Wi‑Fi it always uses the live site (your latest publish). Without Wi‑Fi it uses the copy. There is no separate “offline app” to switch back from.
