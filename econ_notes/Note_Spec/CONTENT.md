# 用字、雙語、欄目與人名

這份管**寫甚麼、跟誰的原文、用誰的名字**。版面 class 見 LAYOUT.md。

## 1. 雙語標記

每個學生看得到的中文塊，都要有英文 twin。英文預設 `hidden`，由頂欄切換。

塊級：

```html
<p class="zh">中文。</p>
<p class="en" hidden>English.</p>
```

行內：

```html
<span class="zh">中文</span><span class="en" hidden>English</span>
```

列表：**整條 `li` 切語言**，不要中英塞進同一顆子彈。

```html
<ul>
  <li class="zh">中文點</li>
  <li class="en" hidden>English bullet</li>
</ul>
```

標題可把節號留在外面、題目切語言，或整行用 `中文標題 | English title`（Markdown 組裝器會拆）。

練習解釋用成對的 `.why.zh` / `.why.en`。

網址帶語言：`?lang=zh-hk` 或 `?lang=en`。頁內所有回首頁、教具、書本練習連結都要跟著改 query，不要寫死一種語言。

## 2. 哪些照抄課本，哪些課堂改寫

| 內容 | 規則 |
|---|---|
| 小測試 Quiz、例題拆解 Guided Example、公開試題 Public Exam | **照抄該語文課本**（題幹、選項、對錯、人名、專有名詞、書內特殊用字）。中文題用中文書；英文題用英文書。不要改口語、不要換成課堂人名。 |
| 應試攻略 Exam Tips | 標題與準則跟該語文書。可加一句課堂例子，但判準用字先跟書。英文標題用書上的 Exam Tips 名稱，不要自撰口號。 |
| 定義框 | 核心定義跟該語文書。框外解說可用課堂句子。 |
| 解題思路 Thinking process | 課堂自製。放在例題拆解的**題目之後、答案之前**。中文標題「解題思路」；英文 *Thinking process*。步驟裡的術語跟書。 |
| 小練習、生活案例、課堂例子 | **不要**整段抄課本個案。用香港中四生活改寫。可保留書的計算結構。 |
| 學習重點 | 用 DSE 能做到的動詞（說出、分辨、計算、解釋、指出）。對齊該章考點，不要寫成願望清單。 |

**中英不是互譯。** 改英文本先對英文書該頁；沒有對應段才自譯。書若有明顯文法或用詞選擇，優先跟書。

**用字要準，但準則是通用的：** 量詞跟所指物件；近音／近形英文不要寫錯；否定句用書與考試慣用的「不足以／不足」這類，不要用會改變經濟學含義的口語。發現某一章有反覆出現的錯詞，寫進該章 `.warn`，不要只在對話裡改一次。

## 3. 人名

課堂自製內容只用這套（中英成對，固定配對）：

| 中文 | English |
|---|---|
| 樂澄 | Chloe |
| 欣怡 | Yan |
| 文諾 | Marcus |
| 家明 | Ka Ming |
| 梓柔 | Tsz Yau |
| 嘉欣 | Ka Yan |
| 梓軒 | Tsz Hin |

課本欄目裡的人名**只留在 Quiz／Guided／Public**，不要改成上表。也不要把上表的人寫進官方欄目。

課堂故事用香港地名與日常場所即可（地區、交通、校園、兼職），不要寫真實學生全名。

## 4. 官方欄目 vs 課堂欄目

官方框跟**中文書的頁次順序**出現，即使當前顯示英文。不要為了「把所有 Quiz 放一起」而重排。英文框的用字跟英文書；頁碼用該語文書的印刷頁。

課堂自製的小練習、生活案例，插在**剛教完的那個概念後面**，不必等整節結束。

| 種類 | class | 中文標 | 英文標 | 頁碼 |
|---|---|---|---|---|
| 小測試 | `.tb-box.tb-quiz` | 小測試 *章.號* | Quiz *章.號* | `課本 p.n` / `Textbook p. n` |
| 例題拆解 | `.tb-box.tb-guided` | 例題拆解 *章.號* | Guided Example *章.號* | 同上 |
| 公開試題 | `.tb-box.tb-public` | 公開試題　HKDSE 年，卷，題 | Public Exam　HKDSE year Paper Q | 同上 |
| 課堂小練習 | `.tb-box.tb-quiz` | 小練習 *章.號* 或 *章.號A* | Quick check … | 無 |
| 生活案例 | `.tb-box.tb-quiz` | 生活案例　短題 | Living case　… | 無 |

編號：官方編號跟書。課堂練習不要盜用官方編號；用「小練習 2.3A」或「小練習　題名」區分。

有頁碼的表頭：

```html
<div class="tb-head">
  <p class="tb-lab"><span class="zh">小測試 2.1</span><span class="en" hidden>Quiz 2.1</span></p>
  <span class="tb-pg"><span class="zh">課本 p.12</span><span class="en" hidden>Textbook p. 12</span></span>
</div>
```

例題拆解固定順序：題目（照書）→ `.think` 解題思路 → `.tb-ans` 或答案表。不要答案先於思路。

一題一個 `.q`。題號用 `.mark`（題 1 / Q1）。答案句式：中文「答案：」+ `.ans`；英文 `Answer:` + `.ans`。選擇／對錯題把選項或 True/False 留在題幹，答案只填對的那邊。

## 5. 應試攻略怎樣寫

- 標題一行：「應試攻略：……」／書上的 Exam tip 原題。
- 凡是 **(1) (2)** 或書裡分點：**各佔一個 `h4` + 正文**（或一條清單的一項）。禁止整段擠在同一個 `<p>`。
- 「另外：……；……。」這種串句，拆成獨立小標題或條列。
- 每一條準則配：**正確例子** + **易錯對立**（學生會寫成的那句）。不要只寫抽象口號。
- 攻略裡也可以有 `.ans`，讓填空模式變成「先講準則再揭關鍵詞」。

## 6. 填空（`.ans`）

包的是考點詞，不是整句。

```html
<p class="zh">機會成本是<span class="ans wide">被放棄的選項中價值最高者</span>的價值。</p>
```

- 短詞：`<span class="ans">…</span>`（填空時約 5em 底線）。
- 長語：加 `wide`（約 14em）。
- 官方框裡的答案同樣用 `.ans`，讓三種模式對官方題也有效。
- `.why` 裡需要揭的關鍵詞也可以包 `.ans`；不要把整段解釋藏掉。

不要：為了填空而把無關形容詞藏起來；不要用圖片當答案。

## 7. 學習重點、詞彙、頁眉、頁腳

**學習重點：** 章題與目錄之後、第一節之前。Checkbox，每項一件 DSE 能做的事。中英成對。不要寫「了解本章」這種測不到的句子。

**詞彙 `#sgl`：** 章末。`.glossary` 每列英文術語 | 中文術語。只收本章要用、考試會寫的詞。不要做成百科。

**頁眉 kicker（一字不改，英文兩行）：**

```html
<p class="kicker">
  <span class="zh">HTMS 經濟科課堂筆記 | 編輯：Mr. Sam Wong | 重要聲明：本課堂筆記僅供已購買課本之學生使用，並僅限內部參考。</span>
  <span class="en" hidden>HTMS Economics Lesson Notes | Editor: Mr. Sam Wong<br>Important: These lesson notes are intended only for students who have purchased the textbook and are for internal use only.</span>
</p>
```

`.kicker` **不要** `text-transform: uppercase`。

**頁腳：** 一句聲明即可——定義跟各語文書；課堂例子為校本改寫；官方欄目用課本原文；不要把課本插圖放到網上。

**Lead 句（可選）：** 可用一句說明本章對齊書的哪些節、以及刻意不收入的課題「見後續」。不要在 lead 教新概念。畫面 CSS 可把 `.lead` 藏起；仍建議寫，方便維護者。

## 8. 節的內文節奏

每一節大致：

定義 → 必要解說 → 圖或表 → 應試攻略 → 課堂例子 → 教具連結（若有）→ 該概念的小練習 → 該頁出現的 Quiz／Guided／Public

不要在一節開頭堆三個定義卻沒有例子。也不要例子先於定義。

長節可在章內再切 `h3`／`h4`，或拆成 `1.3A`、`1.3B` 這種目錄錨點。錨點 id 用 `s` + 節碼，例如 `#s21`、`#s13a`。詞彙固定 `#sgl`。

## 9. 邏輯與表：不要跳步

課本流程圖有的中間狀態，筆記都要有。不能為了「好排」而三步走完五步。

分叉再匯合用 `.chain`，直線短因果用 `.flow`。中文格跟中文書用字；英文格跟英文書用字。

比較表要讓「選了／放棄了／其他」在視覺上可指（見 LAYOUT 的表 class）。標「較低成本」時用約定 class，不要只改字色。
