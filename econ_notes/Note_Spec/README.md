# 課堂筆記規格包（給下一份 AI）

這份資料抽出**可重複使用的設計意念、規則與方法**，讓之後每一章用同一套邏輯。它不是某一章的內容大綱。

現有章節的 HTML 只是這套原則的一次實作。寫新章時：跟這裡的規則，對該章中英課本；**不要**把舊章的例子、定義、欄目編號或教具搬過去。

## 給 AI 的閱讀順序

1. **PRINCIPLES.md** — 這套筆記是給誰用、解決甚麼課堂問題、甚麼不要做。
2. **CONTENT.md** — 哪些照抄課本、哪些課堂改寫、雙語、人名、填空、應試攻略。
3. **LAYOUT.md** — 一頁的骨架、頂欄、元件何時用、三種閱讀模式、畫筆／列印。
4. **TOOLS.md** — 何時做互動教具、一章一個 lab、怎樣掛回筆記。
5. **WORKFLOW.md** — 改哪個檔、怎麼組裝、首頁、PDF、發布。
6. **CHECKLIST.md** — 交貨前逐項核對。

老師日常改一章：CONTENT + WORKFLOW 通常就夠。新開一章或改版面：六份都讀。

## 這套系統是甚麼

靜態 HTML 課堂頁，給 **iPad 投影／學生自讀／列印**。同一網站、同一套頂欄、同一套 CSS class。新章只加內文與（如有需要）該章 lab，不重做殼。

對齊課本系列：**UPEP《Economics in Action》／《活用經濟學》**。中文版與英文版不是互譯。

## 刻意不寫進這份包的東西

- 任何一章的定義、題目、故事、頁碼對照表
- PWA／離線下載／每日解鎖（全站層，不在筆記章內重做）
- 已獨立上架、禁止改動的模擬器（見 WORKFLOW.md）

Markdown 是這份規格的來源。若資料夾裡有 `.docx`，以 Markdown 為準。
